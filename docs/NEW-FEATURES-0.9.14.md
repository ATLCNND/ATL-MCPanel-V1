# 0.9.14 新增功能说明

本文面向**使用者**（管理员与实例用户），说明 0.9.14 带来的三项变化：
容器化隔离、日志分析页、公网端口安全限制。

---

## 一、容器化隔离（让实例跑在容器里）

### 它解决什么问题

在此之前，实例进程虽然已经以**专用系统用户**运行、实例目录也互相隔离，但它仍然能：

- 读到节点上任何"世界可读"的文件（`/etc/passwd`、其它服务的配置）；
- 连上节点本机上的服务（面板、Daemon、frp 管理口、SSH）；
- 看见节点上的**所有进程**；
- 在节点文件系统的很多地方写文件。

容器化把这四条一起关掉：实例跑在一个独立容器里，有自己的网络、只读的根文件系统、
被丢弃的全部 Linux 权限，只能写自己的实例目录。

> **它不改变"能不能执行命令"。** 控制台那一行由谁解释，取决于实例进程是谁：
> 启动脚本以 `exec java` 结尾 → 由服务端解释，只是游戏指令；
> 若脚本里留着一个读 stdin 的 shell（如 `exec bash`），那就是任意系统命令 ——
> 区别只在于**它跑在容器里还是节点上**。所以推荐继续使用 `exec java` 写法。

### 怎么开关（**仅总管理员**）

打开实例 →「启动」页 →「容器化隔离」：

- 勾选即开启，取消即关闭，**下次启动生效**；
- 实例**运行中无法修改**（会提示先停止）—— 避免"界面显示改了、实际还在旧模式跑"；
- 开关**只有总管理员能改**。这不是权限洁癖：隔离限制的正是实例里的进程，
  而实例所有者本来就能通过启动脚本/控制台执行命令 —— 若他自己能关掉隔离，
  隔离就只是一句承诺。协作者与实例所有者能看到状态，但不能改。

页面上会同时显示节点是否具备条件（Docker 版本与所用镜像），
条件不满足时会明确说明原因，而不是让开关看起来可点却无效。

### 开启后要注意什么

| 事项 | 说明 |
|---|---|
| 实例目录的路径 | 容器内看到的是 **`/data`**。启动脚本里请用 `/data/xxx` 引用实例内文件 |
| 端口 | 只发布到节点本机回环（`127.0.0.1:<实例端口>`），公网仍通过穿透访问，用户侧无变化 |
| 插件/模组 | 正常工作；它们写入的数据都在 `/data` 下 |
| 出网 | 正常（online-mode 需要连 Mojang 会话服务器，已实测可用） |
| 资源限额 | 由容器运行时实施（内存/CPU），面板上设置的上限照旧生效 |
| 停止/重启/强杀 | 与原来完全一致；强杀在容器模式下走"删除容器"，不会留下孤儿进程 |
| 与别的实例 | 完全隔离：各自独立网络，互相连不到对方的端口 |

### 基础镜像从哪来

节点上需要一份 `atl-mcpanel-runtime` 镜像，**随节点部署包分发**（`runtime/` 目录），
`deploy/install.sh` 会自动 `docker load`，不需要节点能上外网。
也可以从 GitHub Release 单独下载后手工导入：

```bash
docker load -i atl-mcpanel-runtime-<版本>-amd64.tar.gz
docker tag atl-mcpanel-runtime:<版本>-amd64 atl-mcpanel-runtime:latest
```

镜像里**故意不含 JDK**：节点上的 `/usr/lib/jvm` 以只读方式挂进容器，
所以"在面板里按实例选 Java 版本"照旧可用。

### 怎么回退

面板上取消勾选即可，下次启动就回到直接运行在节点上的模式。
已经建好的容器会在实例停止/强杀时一并清理，不需要手工 `docker rm`。

## 二、日志分析页（第三方日志分析，默认关闭）

控制台与玩家之间的「**日志分析**」页：列出崩溃报告与最近的日志文件，
一键上传给第三方服务分析，AI 结论以流式方式实时显示；历史记录可回看结论、
打开原日志、删除云端副本。

### 隐私与开关（请务必知悉）

- 该功能**默认关闭**，需要管理员在面板配置里显式打开（`logshare.enabled`）；
- 提供服务的是**第三方**（[LogShare.CN](https://logshare.cn)），日志会离开你的服务器；
- **每次上传前都会弹窗告知**，并提供「**过滤玩家聊天行**」（**默认开启**）：
  对方的自动脱敏只处理 IP，**不会**过滤玩家名与聊天内容，所以这一项默认替你去掉；
- 必须**手动勾选**同意对方的《服务协议》与《隐私政策》才能继续
  —— 服务端同样校验这个勾选，不只是前端藏了个按钮；
- 上传后可以随时「删除云端副本」（凭上传时返回的令牌），对方的默认保留期是 15 天。

### 分析在中途切换页面会怎样

不会丢。分析在服务端**后台运行**，切换页面或关闭浏览器都不影响它跑完，
结论会落库，下次打开直接看结果；同一份日志也不会重复消耗对方的分析额度。

## 三、公网端口：不允许把节点自身服务暴露出去

新增了一条安全检查：**穿透目标（本地端口）不能指向节点自身的服务**。

被拒绝的典型端口：`22`（SSH）、`3306`/`5432`/`6379`（数据库）、
`7000`/`7400`（frp）、`8080`/`8443`/`9090`/`9091`（面板与 Daemon），
以及**全部特权端口**（< 1024，需要 root 才能监听的服务都在这个区间）。

为什么：frpc 以 root 运行，而穿透配置固定指向节点的本机地址 ——
填 `22` 就等于把节点的 SSH 登录入口公开到全网（爆破面从内网变成全网）。

正常的游戏与插件端口不受影响，例如 `25565`、`25566`、`8123`（网页地图）、
`24454`（语音）都能正常开。
